# Codex Vault

This is a personal knowledge vault organized for long-term reference and retrieval.

## Structure

- `raw/` — One-time exports from external sources (never edited after landing)
- `mirror/` — Synced copies of external projects (refreshed by `/sync-projects`)
- `wiki/` — Curated knowledge base (index, log, concepts, projects, people, placements)
- `journal/` — Time-ordered entries, daily notes, meeting logs
- `content/` — Drafts, articles, and published pieces
