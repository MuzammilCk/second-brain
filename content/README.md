# Content

Drafts, articles, and published pieces — the output layer of the vault.

## Structure

- `drafts/` — Works in progress
- `published/` — Finished pieces with publication metadata
- `archive/` — Old versions and retired pieces

## Conventions

- Frontmatter with `title`, `date`, `status` (draft/review/published/archived), `tags`, `canonical_url` (if published)
- Link to [[wiki]] pages for concepts, projects, people, placements
- Keep source in `content/`, publish elsewhere
