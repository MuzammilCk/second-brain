# review

Run an active-recall quiz based on concepts in the wiki.

## Flow
1. Locate target concept page under `wiki/concepts/` (or select due/unreviewed pages).
2. Formulate exactly one practical question requiring application of the concept.
3. Wait for user response, evaluate gaps, and reinforce key points.
4. Update frontmatter `reviewed` and `last-updated` dates.
