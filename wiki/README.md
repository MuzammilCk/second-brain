# Wiki

Curated knowledge base — the edited, organized, and interconnected layer of the vault.

## Structure

- `index.md` — Entry point and table of contents
- `log.md` — Chronological log of significant changes and decisions
- `concepts/` — Definitions, frameworks, mental models
- `projects/` — Project pages with status, context, and links
- `people/` — Contact info, context, and interaction logs
- `placements/` — Where things live (tools, accounts, servers, paths)

## Conventions

- Use `[[wikilinks]]` for internal references
- Keep each page focused and atomic
- Update `log.md` when making significant changes
