# Codex Second Brain & Autonomous Developer Vault

Autonomous personal knowledge vault, engineering decision registry, and portfolio compilation system. Features strict 4-tier security boundaries, continuous automated telemetry synchronization with GitHub, and cross-agent coordination for Claude Code and Antigravity.

## Problem & Overview

Engineering knowledge, architecture decisions, and project states easily fragment across disparate repositories, chat threads, and scratchpads. Codex solves this by serving as a single source of truth for technical memory, active sprint velocity, and public portfolio projections while enforcing strict information barriers against credential and private data leakage.

## Architecture

- **Tier 1 (Private Vault)**: Restricted local dossiers, placement interviews, and sensitive operations.
- **Tier 2 (Progress Radar)**: Stack inventory state, algorithm tracking, and machine-readable GitHub telemetry.
- **Tier 3 (Curated Wiki)**: Architectural decision records (ADRs) and project case studies.
- **Tier 4 (Public Site Projection)**: Headless static site generation for public portfolio deployment.
